Formulas & how this works

For a first-order RC filter the cutoff (−3 dB) frequency is the same for low-pass and high-pass:

f_c = 1 / (2πRC) τ = RC = 1 / (2π·f_c) ω_c = 1/τ

Low-pass (output across C)

|H(f)| = 1 / √(1 + (f/f_c)²) |H|_dB = −10·log10(1 + (f/f_c)²) φ(f) = −arctan(f/f_c)

At f = f_c: gain = −3.01 dB, phase = −45°. Far above f_c the roll-off is −20 dB/decade and phase → −90°.

High-pass (output across R)

|H(f)| = 1 / √(1 + (f_c/f)²) |H|_dB = −10·log10(1 + (f_c/f)²) φ(f) = +arctan(f_c/f)

At f = f_c: gain = −3.01 dB, phase = +45°. Far below f_c the slope is +20 dB/decade and phase → +90°.

Time domain

Step (LP): v(t) = V·(1 − e^(−t/τ)) Step (HP): v(t) = V·e^(−t/τ) Rise time (10–90%): t_r = τ·ln 9 ≈ 0.35/f_c

Group delay

τ_g(ω) = RC / (1 + (ωRC)²) τ_g(0)=RC, τ_g(ω_c)=τ/2
